# William Puma — Portfolio

Personal portfolio for William Puma, a Software Developer focused on web and mobile products.

## Stack

- Next.js, React and TypeScript
- Tailwind CSS
- Framer Motion
- Zustand

## Development

```bash
npm run dev
```

## Production validation

```bash
npm run build
./node_modules/.bin/tsc --noEmit
```

The production build generates `public/sitemap.xml` and `public/robots.txt` through `next-sitemap`.
